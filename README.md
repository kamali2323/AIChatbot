# AI Chatbot - Java

## 📌 Project Description

This project is a simple AI Chatbot developed in Java as part of the CodeAlpha Java Programming Internship.

The chatbot interacts with users through a console-based interface. It accepts user input, processes the text using a separate `BotLogic` class, and generates appropriate responses. The conversation continues until the user enters **"bye"**.

## 🚀 Features

* Interactive console-based chatbot
* Real-time user interaction
* Separate chatbot logic using OOP principles
* Continuous conversation loop
* Exit command support ("bye")
* Easy to extend with additional responses

## 🛠 Technologies Used

* Java
* Object-Oriented Programming (OOP)
* Scanner Class
* String Handling
